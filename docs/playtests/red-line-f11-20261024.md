Private playtest. Static builds, price coverage and mocked runtime checks cannot establish actual Unity/Harmony/gameplay behaviour. This bundle includes the completed full-cost catalog from the preceding playtest.

## Install and startup

1. Close Sea Power. Run the included installer against the existing clone. Confirm its exact green `IN LINE` commit/file count. Fully restart. Enable Anchor Chain, Combat Cost Tracker (`3807187341`) and SEST; use only one SEST copy. Group Manager may remain enabled.
2. Player.log must contain `campaign combat costs installed`, `combat inventory capture installed`, and `Cumulative Combat Costs and Last games embedded in original F11`. Report uninspected-build, missing member or patch errors. Runtime accepts only the previously reviewed Sea Power 0.8.7 Build 261021 hash and captured tracker 0.7.1 hash. New game/tracker versions require review.

3. Start a new mission and press F11. Check that **This mission**, **Cumulative Combat Costs** and **Last games** sit within the original panel. This mission retains the original tracker controls and values. No separate F10 viewer should open.
4. On Cumulative Combat Costs, compare **This campaign**, **Recorded game sessions** and **Current mission detail**. The last is available while playing and includes registered land losses, recorded parked-aircraft losses and captured itemized lost stores. Values explicitly use USD and the selected historical/current basis. Native currency conversion remains on the original tab.
5. Fire a known weapon; expend a sonobuoy/decoy. Hide F11, repeat, reopen. Counts should continue. Lose one ship with a known magazine, one land unit and one aircraft; each platform and its remaining itemized stores must appear once in the detailed SEST view. A native unreported aircraft loss cannot be synthesized. Virtual deck-ammunition point pools stay `+ ?`.
6. Save mid-mission, leave normally, then continue that save and expend one more known round. Its ended-session record must update, not count the same session twice. Start a fresh attempt/replay: it should become a separate recorded session. A forced process kill may lose the latest unflushed record.
7. In the **Task Force menu between missions**, press F11. The cumulative/history panel must open there, and F11 must hide it again. Open **Last games**, select a prior result and return to the list. Inspect earlier native debriefs from the current campaign as well as newly recorded sessions. Earlier standalone games played before this recorder cannot be reconstructed.
8. Complete two campaign missions. **This campaign** must equal their two saved debriefs once each, excluding the unfinished current mission and retry history. Reopen/restart/replay: it must not accumulate duplicate completed missions. Last games may retain distinct attempts/replays. Change price mode in a separate restart; raw old quantities should reprice. Viewing totals/history must not change campaign quantities.
9. At ordinary and small resolutions and with the author's overlay scale/position settings, check that tabs, history pagination, detail lines and totals fit inside the panel. Switch repeatedly, open native popups, hide/show F11, and return to the Task Force menu. Report any clipped controls or persistent graphics/input changes.
