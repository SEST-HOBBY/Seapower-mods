# O10 map and UAV report

The PC report identifies controllable F-15EX aircraft missing or unidentified on the map in Southern Watch O10, a forward UAV section labeled MISSING, and repeated NullReferenceException messages from SeapowerUI.MapKnownUnits.Update. The two screenshots show the same exception, not two independent failures.

## Definition fix

The sest_uav_forward unit aliases the stock small airfield but had no variants companion under its own id. O10 therefore emitted no VariantReference. The pack now defines one local variant, supplies both Default and Variant1 display names, and emits Variant1 in all eleven enhanced missions and D9 Joint Fires School. Mission nations and two-aircraft custom UAV groups are retained. This repairs the missing metadata; native UI behavior still needs PC confirmation.

## Eagle and map exception status

Both O10 Eagles are Taskforce1Aircraft entries, Squadron1, with the conventional Strike183 fit and a valid friendly HomeBase. No allegiance, IFF, sensor, weapon or aircraft-performance changes were made. The captured Formation Manager 0.2.16 source patches camera input and the Formation Manager toggle, and adjusts map visuals; it does not patch MapKnownUnits.Update directly. The wrapper name in the exception does not identify the responsible plugin or prove a Formation Manager defect. The older PC capture predates this reproduction.

Collect current Player.log, BepInEx.log, saved LoadOrder and relevant map/plugin DLLs using tools/export-map-diagnostics.ps1 after reproducing and closing the game. -IncludeGameAssembly adds the installed Assembly-CSharp.dll so the native failing method can be inspected read-only. The capture freezes the manifest input before writing it, avoiding the earlier self-hashing lock error. It changes no installed files or settings.

Retest a fresh O10 after the metadata fix. Check Eagles and UAV labels before minute ten and again after Moth 11 joins. If the map still fails, compare a fresh run with Group Manager disabled, then restore it; test Better TacMap separately if needed. Preserve logs for each run.
