# 26 October 2026 - World Sandbox Poseidon model-quality correction

**Status: source and distribution patch; not yet built on the PC or tested in Sea Power.**

The existing World Sandbox and Regional Expansion both field six US Navy P-8A
formations (12 aircraft) using Red Storm Arsenal's `usn_p_8a`. That unit's
model resources point to P-3 Orion geometry, as observed in the 25 October
Southern Cross playtest. Its appearance is therefore not appropriate for 2028
Poseidons.

The 2027 Capabilities unit `usn_p8_2027` already exists in the installed
collection, uses `P8_Poseidon.obj`, has a US Navy squadron and ASW/AntiShip/
LRASM loadouts. The World Sandbox builder alone now converts the old reference
to that unit, keeps the opening quantities and bases, and excludes the
P-3-bodied duplicate from the **World Sandbox purchase catalogue**. Other
campaigns and upstream mods are unchanged; the original research register
continues to record the asset named by its source.

Both World Sandbox variants are generated independently and retain the same
campaign IDs. Their expected force counts remain 267 and 293; the purchase
catalogues and value tables become 1,560 entries, one fewer obsolete option.

Build and validation:

```
python tools/build_all.py --from-scratch
python -m unittest tools.tests.test_world_sandbox_poseidon
python -m unittest discover -s tools/tests -p "test_*.py"
git diff --check
git status --short
```

In game, start each sandbox as a NEW campaign, inspect a US Navy P-8 (US livery,
actual Poseidon/737 model), launch an ASW patrol, check the US Navy's purchase
catalogue, run a battle and save/reload. Verify the separate RNZAF Kiwi 01
fix in Southern Watch O2. Never overwrite existing saves. Do not publish before
testing with a refreshed Workshop capture.
