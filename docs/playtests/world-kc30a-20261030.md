# World Sandbox: the KC-30A priced as a tanker, PC check (30 October 2026)

**Status: built and checked from source on the 28 Oct Workshop capture; not yet built on the PC or seen in Sea Power.** Never overwrite an existing save.

## What changed

Since the 28 Oct 2026 Workshop refresh two mods ship `aircraft/aus_a330_mrtt.ini`, the RAAF KC-30A: Euromod Modern RAN (3820759806), whose copy is new in that update, and French Air Force (3758943352), which until then was the only one. Euromod's copy wins in the SEST load order (position 36 against 191 in `data/load-order.tokens.txt`), and it calls the aircraft an airliner (`Role=Airliner`); French Air Force's calls it an AEW aircraft (`Role=AEW`). Neither is a tanker.

Both World Sandbox campaigns, the original (`sest.world_sandbox_2028`) and the Regional Expansion (`sest.world_sandbox_2028.regional`), value an aircraft by its first Role, so the KC-30A, 242 (an AEW's value) until now, would have become an airliner at 2. The builder now values it as a Tanker, 60, whichever copy wins (`AIR_ROLE_OVERRIDE` in `integration/world-sandbox/build_dynamic_campaign.py`), and `integration/world-sandbox/draft/conversion.json` records the choice: "Role Tanker, SEST choice (the winning file says Role Airliner)". The override names that one unit, so:

- **Same place.** The KC-30A is a purchase only, blue, Australia, listed once in both worlds; no force places it.
- **Price band 0 instead of 1.** 60 is in the first band (up to 120), where the KC-135 Stratotanker, KC-130J and Il-78 already sit, valued 2 because their files say `Role=Airliner`; the RAF Voyager (`uk_a330_mrtt`, French Air Force's, `Role=AEW`) stays at 242 in band 1. Those four are unchanged: the owner's decision for this capture was the KC-30A only. The override can take them when a decision is made.
- **Every other value is unchanged.** The 28 Oct capture itself adds three units to both buy lists, valued by the usual rules: Charles De Gaulle & Modern French Navy's Aliaca UAV (`fr_aliaca`, 28, Role Recon) and Floréal frigate (`fr_ffg_floréal`, 130, 3,800 t), and Spanish Navy Cold War's S-55 (`spa_s-55`, 39, Role ASW). Both worlds list 1,563 purchases instead of 1,560.
- **Bases, forces and patrols are unchanged.** 141 bases, 267 forces and 49 patrols in the original; 156, 293 and 54 in the Regional Expansion.
- **Combat Cost Tracker is unchanged for the KC-30A.** The tracker's own catalog prices `aus_a330_mrtt` (180,000,000 / 230,000,000) and both copies read it; `docs/combat-costs/cost-list.csv` only records the new owner.

An old save keeps the values it started with; only a new campaign prices the KC-30A at 60.

### Bomber Stream's tanker flies Euromod's file

Southern Watch O8 Bomber Stream places `aus_a330_mrtt` (its `Taskforce1Aircraft8`, `SquadronReference=Squadron1`), so in game it now resolves to Euromod's copy, not French Air Force's. The mission file is unchanged. What is different about the aircraft: a second sensor (an ESM `AircraftRWR`), a refuelling boom beside the hose (`TankerSystems=Boom,ProbeAndDrogue`, with a `BoomOffset`; French Air Force's copy has the hose only), the aircraft itself taking fuel by boom, and a No. 33 Squadron livery the mod ships (binary content, not in the text export). Both copies define `Squadron1` for Australia. The mission's two F-22s take fuel by boom (`usaf_f-22_s6`, `ReceiverSystems=Boom`), so they can now refuel from the KC-30A; the J-16s' probe is unaffected. The four RAAF F-35As fly SEST's own copy (`SEST_RAAF_F-35A_JATM`, built on Greene's retired RAAF F-35A, `mods-source/_retired/3514484654`), which states no `ReceiverSystems` at all, so whether a Lightning can take fuel from the boom is not a question this change answers. `docs/campaigns/side-operations.md` still credits the KC-30A to the French Air Force mod.

```
python3 integration/world-sandbox/build_dynamic_campaign.py   # runs check_dynamic_campaign.py and build_regions.py

python3 -m unittest tools.tests.test_world_sandbox_kc30a tools.tests.test_world_sandbox_rebuild tools.tests.test_world_sandbox_poseidon tools.tests.test_regional_expansion
python3 -m unittest discover -s tools/tests -p "test_*.py"
```

`tools/tests/test_world_sandbox_kc30a.py` pins the override to the KC-30A, the Tanker value in both committed campaigns and the dist copies, and that Euromod's copy still wins and still does not call the aircraft a tanker: if an author fixes the role, the override is to be retired.

## On the PC

1. Start the original **World Sandbox** as a **new** campaign. START CAMPAIGN reaches the strategic map with no error.
2. Open the Australian purchase list. The KC-30A is listed once, in the first price band, at 60. Note the name shown: Euromod's file names it "KC-30A", French Air Force's "KC-30A MRTT"; the game's language merge decides which is displayed.
3. Buy one and base it at an Australian air base. It appears there as an A330 MRTT in RAAF markings, takes off when tasked and comes back.
4. Repeat steps 1 to 3 in the **Regional Expansion**.
5. Start **Southern Watch O8 Bomber Stream** (a stand-alone mission). The RAAF KC-30A spawns with its No. 33 Squadron livery and no missing texture (magenta), and its RWR shows as a sensor. Task an F-22 to refuel from it: with Euromod's copy it should take fuel by boom. Then fly the mission as usual.
6. If you have an old World Sandbox save, open a **copy** of it: it loads, and its purchase list still shows the KC-30A at the value it was saved with.
