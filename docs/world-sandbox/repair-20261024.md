# World Sandbox startup repair - 24 October 2026

Dynamic Campaign Mod v0.25.0 fails at Start Campaign with "no ch_ffg_jvh".

## Cause
EUROMOD-Armada de Chile (Workshop 3776730617) renamed the L-class frigate
from ch_ffg_jvh to ch_ffg_jacob_van_heemskerck in the 24 October capture.
The generated world still referenced the retired id in values and purchases.
The register, deployed forces and base count are unchanged.

## Repair
- Use the current hull id for new purchases, not both class ids.
- Keep a legacy hull alias for older saves plus its two named variants and names.
- Preserve USD 197,000,000 historical and USD 800,000,000 current prices for
  both ids using the established Dutch-class cost comparator.
- Explicitly build World Campaign before Combat Costs.

## QA
Rebuild with: python tools/build_all.py --from-scratch
Test with: python -m unittest tools.tests.test_world_sandbox_legacy
Run the remaining Python and PowerShell suites on a full checkout.

Windows game acceptance is still needed: restart the game with the current
Workshop dependencies, select the SEST World Sandbox, START CAMPAIGN and confirm
entry into the paused map; then test CONTINUE on a COPY of the existing save
to check both old named hull variants, save/reload, purchase, sortie and combat.
Do not overwrite the original save. Check BepInEx/LogOutput.log and Player.log
for subsequent errors. Code/data checks cannot certify the engine runtime.
