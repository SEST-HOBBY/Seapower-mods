# Southern Watch — mod coverage

Generated by `integration/campaign/build_pack.py`. Do not edit.

The campaign is 26 missions built from 371 placed units. Every mod in the canonical load order (`data/load-order.tokens.txt`) and every SEST source pack appears below, with the mechanism that makes the game read its files. Coverage is measured on the load order rather than on catalog status, because five enabled entries are catalogued deprecated and two WIP while still being required donors.

| class | meaning | mods |
|---|---|---|
| `unit` | places the unit; this mod wins its file | 130 |
| `variant` | supplies the hull variant the placed unit uses | 3 |
| `squadron` | supplies the squadron the placed airframe flies from | 10 |
| `store` | supplies a round the placed unit's loadout hangs | 6 |
| `library` | ships no file a mission can name — systems, effects, UI or a bare dependency marker — and applies install-wide | 5 |
| `shadowed` | every file it ships is outranked by something above it; nothing it contains can load | 2 |
| `campaign` | this pack - the campaign being measured | 1 |

Sea and land positions are snapped to points already used by a loading mission; the furthest any anchor had to move is 15.4 NM.
