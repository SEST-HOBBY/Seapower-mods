# Owner-supplied photos without a recorded source (21)

These are the photos in `integration/gallery/added/` whose row in `integration/gallery/added-photo-credits.csv` has no creator, licence or source page (the 22nd row, `b-52g.jpg`, records U.S. Air Force, public domain, af.mil, and is left out). The gallery (`Gallery/catalogue.js`, `Gallery/PHOTO_CREDITS.txt`) shows each as 'Credit to be added · Not recorded', 'Supplied by: the SEST author (October 2026)'.

**This is a source search, not a permission request.** The rights holder of each photo is unknown, so there is nobody to ask yet. For each photo the owner first needs to find where it came from (the site, the photographer or agency, the licence). Then one of three things follows:

1. Free licence or public domain (for example a US government photo, or Wikimedia Commons under CC BY / CC BY-SA): record creator, licence and source page in `added-photo-credits.csv`, run `integration/gallery/apply_added_photos.py`, rebuild. No request needed.
2. Copyrighted with a findable owner: ask that owner (the tracker has one line for all of these; add a line per owner once known).
3. Not found, or not clearable: replace it with a reviewed Commons photo, or remove it from the gallery, profiles and briefings.

How to search: reverse image search on the original file in `integration/gallery/added/` (Google Lens, TinEye, Bing Visual Search, Yandex for Chinese and Russian subjects), then Wikimedia Commons, DVIDS (dvidshub.net) and the service photo sites for US subjects. The hints below are guesses from the file name, size and subject, not findings.

Where each photo ships: `Gallery/images/...` (the original bytes, checked against `added/` by `integration/gallery/build_patch.py`), encyclopedia pictures `ui/profiles/<unit>.png` (resized with the credit line on the picture), and mission-briefing recognition pictures `sest_rec_<asset>.png` / banners `sest_banner_<asset>.png` (each briefing ships twice: under `campaigns/` and `missions/`).
