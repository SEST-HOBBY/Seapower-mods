1. RECORD THE PC PASS AND THE TARGET GAME BUILD
Finish the renamed walkthrough in README-FIRST.txt. Keep your last SETUP result, test notes and capture. The compiled features in this kit target 0.9.3 Build 261116 public beta, file hash beginning aae79728. The default Steam release uses another executable. The included announcement and page text say “public beta”.

For the normal public rollout, finish the beta playtest first. Then, on a default-branch PC or after switching Steam Properties > Betas to None and letting Steam finish, close Sea Power. Open PowerShell inside the new toolkit and run the command below. It captures references and prints a ZIP in Downloads. Send that ZIP for the default-build match, rebuild and PC test. Use the resulting approved toolkit and its updated compatibility wording to publish to that audience. A beta PC pass alone leaves that item open.

  powershell -NoProfile -ExecutionPolicy Bypass -File ".\R15\capture-beta-references.ps1"

If you deliberately choose a beta-only public update, the current text already identifies that scope. Confirm the renamed beta tests before submitting. The following buttons are the same for either release.

2. BRING THE EXISTING COLLECTION UP TO DATE
Open the collection owner page and edit its items. Add the ten links in STEAM-COLLECTION-CHECKLIST.txt that are still missing. The main item's Required Items already listed all 209 dependencies when checked on 22 November. Recheck both lists after saving. Expect the main pack and 209 dependencies in the collection. Use STEAM-COLLECTION-TITLE.txt and STEAM-COLLECTION-DESCRIPTION.txt for the collection rename at rollout.

3. STAGE THE EXACT BUILD THAT PASSED
With the game closed, double-click Upload-PC.cmd from the same renamed toolkit whose Prepare-PC.cmd succeeded. It verifies the manifest, prepares a temporary publishing copy under StreamingAssets and prints PICK THIS FOLDER IN THE GAME UPLOADER. Leave that temporary Local entry disabled. Keep the console or copy its full path. The helper also attempts to copy the change note to the clipboard.

4. UPDATE THE MAIN ITEM IN PLACE
Open Sea Power > Mod Manager > Create Mod > Update Existing. Select item 3812461539 and the exact SEST_UP_… folder printed in step 3. Check that the existing ID is selected and that the path belongs to this run. Use STEAM-TITLE.txt, STEAM-PAGE-DESCRIPTION.txt and STEAM-CHANGE-NOTE.txt. STEAM-SHORT-DESCRIPTION.txt is ready for a short-summary field or announcement. Submit when the item, build and audience all match. Confirm the upload succeeded with a non-zero size.
https://steamcommunity.com/sharedfiles/filedetails/?id=3812461539

5. CHECK THE SUBSCRIBER EXPERIENCE
Quit Sea Power. Run Finish-Upload.cmd from the same toolkit. It moves the temporary publishing copy out of the game and retains a verified copy outside it. Let Steam finish downloading the updated item, then run SETUP from the subscribed folder. Check the renamed Mod Manager entry, the GSCO menu and a compatible world save. Reopen the two Workshop URLs and confirm their titles and that Subscribe to all includes the new items. Edit the existing installation discussion with STEAM-PINNED-DISCUSSION.txt or pin it if needed. The first paragraph of the page tells returning subscribers where their former world campaign went.
