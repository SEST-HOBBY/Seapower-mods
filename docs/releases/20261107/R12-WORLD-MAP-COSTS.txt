SEST R12 - WORLD MAP COSTS AND OPENING BRIEF
9 November 2026 | SEST-DEV
Runtime 1.6.2 / UI 1.4.12

OPENING BRIEF
The world opening report now has eight short operational sections, distinct
headings and wrapped 14-point, normal-weight body text. It replaces the very
long automatically generated opening force lists for this scenario. The
campaign selection description uses actual paragraph breaks. Native message
history, closing, guide and pause commands are retained. Other campaigns'
papers are unchanged. Reopening the initial SITREP uses the new presentation.

WORLD MAP COMBAT COSTS
A Combat Costs button is added directly beneath Economy in the left sidebar.
F11 opens the same Cumulative Combat Costs tab. Overview, Forces and Service
remain available in that window. Estimated USD totals appear in the summary;
campaign budget credits are labelled separately in the details.

The strategic report now attaches to the actual CampaignView WindowHost,
rather than the tactical or linear-campaign view. The campaign's own UI tick
also drives updates, with one input/update pass per frame. World window
placement has its own saved bounds and avoids the strategy sidebar and bars.

SCOPE
The existing world save can be used for these UI fixes. No campaign save is
rewritten. The 196 bases, 293 force groups, 54 patrols, 1,586 catalogue entries,
eight command stages, stocks and progression remain as in the previous R12.
The expanded layout still needs a new world if the old save predates it.
Paused battle preparation and the native End battle/debrief flow are retained.
