# CH-53E 超级种马 独立版 v0.1.0

此包从2026-09-14当前大和MOD的CH53运行时文件提取，保留当前模型、贴图、55个子模型、七叶主旋翼、尾旋翼、旋翼与机尾折叠、起落架及前轮舱门动画和挂载位置。原大和MOD不作修改。

## 启用

文件夹放在 Sea Power_Data/StreamingAssets/CH53_Standalone_v0.1.0。游戏内启用“CH-53E 超级种马 独立版 v0.1.0”，同时启用 Euromod（3629144864）和美国海军航空兵（3737267013）。在模组优先级中，让本包覆盖依赖包；无需启用宙斯盾大和。修改模组列表后重新加载并新建测试任务。

在日本直升机列表中查找“CH-53E 海上自卫队”，在美国直升机列表中查找“CH-53E 美国海军陆战队”。独立单位ID分别为 jmsdf_ch53_standalone 与 usmc_ch53_standalone。两个单位共享同一套模型和动画，仅按单位切换涂装，避免重复打包模型。模型、自定义传感器、弹药及挂载标识均独立，可以与原大和包共存。此包不修改舰船航空编组；给其他舰船搭载时需由该舰配置支持相应单位。

## 当前挂载

- 重型反潜：2枚Mk48空投型，30枚SSQ-53F和30枚SSQ-62E，AQS-22吊声。
- 反潜：4枚Mk54（每侧双联），30枚SSQ-53F和30枚SSQ-62E，AQS-22吊声。
- 反舰：2枚NSM空射改型，不装吊声或浮标。
- 搜救运输：无攻击弹药，37人容量，显示当前救援油箱模型。

这是架空任务改型。保留现有Euromod的Mk54双联、浮标和NSM资源，以及美国海军航空兵的相关资源依赖；没有打包这些第三方模组。模型署名和许可见 CREDITS.md。
