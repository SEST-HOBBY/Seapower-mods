ModernSensors / 现代传感器 mod 键值说明
========================================

DLL：plan_ac/ModernSensorsMod.dll
日志：plan_ac/ModernSensors_debug.log

总原则：不写对应键 = 完全原版行为。改 ini 后需要重启游戏；
       只有 DIFF/新增内容才需要写键，原版单位/弹药不用动。


一、导引头 LPI（主动雷达导引头不被 ESM 截获）
--------------------------------------------
位置：弹药 ini（如 ammunition/xxx.ini）

[Guidance]
SeekerLPI = True

说明：
- 只对 GuidanceType = 3（ActiveRadarHoming，主动雷达导引）生效。
- 只让 ESM/RWR 收不到导引头辐射。
- 不改变 2 NM 默认规避、AI 全知来袭路径、导弹物理与命中。
- 不写 / False：原版。


二、雷达 LPI（雷达不被 ESM 侦测）
--------------------------------
位置：systems/sensors.ini 的雷达节

[雷达节名]
LPI = True

可以只加这一行，不必复制整节：

    #!extend systems/sensors.ini

    [Test_Radar]
    LPI=True

说明：
- 只让 ESM 看不见这部雷达；雷达自身探测/跟踪/制导/照射完全不变。
- 反辐射弹、被动雷达寻的、武器系统检查不受影响。
- 扩展文件必须是 .ini，放在任意已启用的 mod 目录下；改完重启游戏
  （游戏只在启动时扫描一次 #!extend 文件）。
- 节名必须对应一个真实存在的雷达定义。


三、MAWS 导弹逼近告警
---------------------
位置：单位 ini（舰船/飞机）

[MAWS]
Range = 10              ; 海里（NM）；0 或不写 = 不装
AngularResolution = 5   ; 度；可选，扇区合并角，默认 5

说明：
- 导弹进入 Range 即“被发现”，不依赖雷达/ESM 先探测到。
- 所有单位生效（含 AI）。
- V2：发现的导弹同时进入威胁列表，参与来袭语音/自动规避/AI 高级规避。
- 玩家单位会画紫色逼近扇区（与 RWR 红扇区同锚点、同几何）。
- AI 单位只参与检测/规避，不画 UI。


四、DIRCM 定向红外对抗
----------------------
位置：单位 ini（舰船/飞机）

[DIRCM]
Enabled       = True
Range         = 5          ; km
Channels      = 1          ; 同时成功干扰的通道数；0 = 关闭
Angle         = -90,90|-90,45
Generation    = 1          ; 代次 1 或 2
Chance        = 0.5        ; 基础干扰概率 0..1
Cooldown      = 3          ; 成功后通道冷却秒数（可选，默认 3）
RetryInterval = 1          ; 失败后同一枚弹重试间隔秒（可选，默认 1）


4.1 生效条件
------------
- 导弹在 _incomingWeapons 中、已发射、未摧毁；
- CurrentTarget == 本机；
- 导引头为 IRHoming（红外）且已开机（isActive）；
- 距离 ≤ Range；
- 方位/俯仰在 Angle 内。

非红外弹（雷达/激光/TV/被动声呐等）不会被 DIRCM 干扰。


4.2 效果
--------
成功时只做一件事：

    missile._deviationMagnitudeWithJam = 1.8898791f

这是原版电子干扰使用的同一个值。之后导弹自己的末端逻辑自动：
- 关闭导引头；
- 永久断制导；
- 关闭近炸引信；
- 偏离瞄准点（原版干扰效果）。


4.3 概率
--------
1 代：
    实际干扰率 = Clamp01(Chance × 难度系数 - AntiCountermeasuresBonus)

2 代：
    实际干扰率 = Clamp01(Chance × 难度系数)

说明：
- 难度系数与原版电子干扰一致，默认 0，即 ×1。
- 抗干扰率取弹药 ini [Guidance] 的 AntiCountermeasuresBonus
  （程序字段 _antiChaffBonus），不是 AntiJammerBonus。
- 例：Chance = 0.9，AntiCountermeasuresBonus = 0.2
      1 代 → 0.9 - 0.2 = 0.7
      2 代 → 0.9
- AntiCountermeasuresBonus 为负数（老式红外弹）会提高实际率；
  最终结果钳在 0..1。
- 若弹药没有写 AntiCountermeasuresBonus，游戏默认值是 1：
      1 代实际率 = 0（完全免疫）；
      2 代不受影响，仍然是 Chance。
- 判定：Utils.RandomFloat(0,1) < 实际干扰率。


4.4 通道、冷却、重试
--------------------
- 成功才占用通道；成功后该通道冷却 Cooldown 秒。
- 失败不占用通道；同一枚弹按 RetryInterval 再次尝试。
- Channels = N 时每个通道独立冷却；有空闲通道才会掷骰。
- 所有带 [DIRCM] 的单位生效（含 AI），没有 UI。


4.5 角度写法
------------
与原版雷达 ViewArcs 相同：

    Angle = 水平min,水平max|垂直min,垂直max

符号：
- 水平：-180..180；0 = 正前，- = 左，+ = 右；
- 垂直：-90..90；0 = 机身水平面，- = 下，+ = 上。

默认：
- Angle 不写 / 为空：水平 -180,180，垂直 -45,45；
- 只写水平段（没有 |）：垂直默认 -45,45；
- 单个正数 n：该轴 -n/2 .. n/2（总角 n），
  例如 Angle = 60 → 水平 ±30，垂直默认 ±45；
- 水平 min > max：表示跨 ±180 的后半球弧，
  例如 90,-90 = 正后方 180° 扇区。

示例：
- Angle = -90,90|-90,45
  左 90° 到右 90°，下方 90° 到上方 45°。
- Angle = -180,180|-45,45
  水平全向，上下各 45°。
- Angle = -60,60
  水平左右各 60°，垂直默认上下各 45°。

角度基于机身局部坐标（舰艏/机头），不是世界方向：
- 水平 = Atan2(局部x, 局部z)；
- 垂直 = Asin(局部y / 距离)。


五、日志
--------
文件：plan_ac/ModernSensors_debug.log

常见内容：
- DIRCM 启用：型号、Range、Channels、Gen、Chance、Cooldown、Retry、Angle
- DIRCM 干扰成功：单位 -> 导弹，距离、实际率、掷骰值、通道冷却
- MAWS 启用：型号、Range、AngularResolution
- MAWS 发现：单位 <- 导弹，距离
- MAWS 扇区已挂接：玩家单位

示例：

[DIRCM]
Enabled    = True
Range      = 8
Channels   = 1
Angle      = -90,90|-90,45
Generation = 2
Chance     = 0.6
Cooldown   = 3
RetryInterval = 1
