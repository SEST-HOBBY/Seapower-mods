MISSILE DISTANT RUMBLE AUDIO

Main asset: Missile_Distant_Rumble_Loop.wav
Alternate: Missile_Distant_Rumble_Loop_B.wav
Each loop is 24 seconds, 48 kHz, mono, signed PCM16 WAV.
Far and VeryFar suffixes are phase-aligned filtered versions of the matching loop.
Use WAV for game looping; MP3 files are listening previews only.

SOURCE AND ATTRIBUTION
USS Mason Fires SM-2 Missile, U.S. Navy, uploaded 20 December 2018.
Credit: U.S. Navy / Seaman Nikita M. Custer.
https://www.youtube.com/watch?v=MJKfFg84Gmc
Source metadata: Creative Commons Attribution license (reuse allowed).
The exact CC license version was not independently verified. Preserve this credit.
Edited derivative: mono downmix, limited background reduction and slow levelling,
filtered spectral balance, rearranged source excerpts and loop crossfades.
Reference material: approximately 12.15-21.55 seconds.
This is recorded missile-flight rumble, not an isolated or authenticated sonic boom.

PROCESSING
Up to 6 dB reduction of stationary pre-launch background; 35 Hz high-pass;
6.5 kHz low-pass; slow gain correction limited to +/-2 dB. Eight overlapping
3.75-second source excerpts form each loop, with 0.75-second transitions.
No pitch shifting, reversing, synthetic rumble or additional artificial reverb.
A and B have matching RMS levels and different excerpt sequences.
Four-times oversampled true peak remains at or below -4.5 dBFS.

RUNTIME USE IN CUSTOM AUDIO LOADER 2.7.0
Only the base A/B loops are installed. Low-pass filtering, gain and Doppler are
calculated at runtime; no Far/VeryFar WAV is used. A/B and start phase vary by source.
The reference contains environmental reverberation. No additional fixed long reverb
is applied on top. This is an artistic motor layer, not a measured pressure signal.
Auditory acceptance and in-game playback remain unverified by offline checks.
