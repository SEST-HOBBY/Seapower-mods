# Higher Resolution Profile Images

No INI settings are required. With the submod loaded, use Sea Power's console commands:

- `save_profile`: export a profile image of the selected object.
- `save_all_profiles`: export all profile images.
- `save_plan`: export a plan image of the selected object.

Images are 1024 pixels wide instead of 512, with their original proportions preserved. Filenames use the vessel/INI name without numeric variant suffixes such as `_0` or `_1`; exports of different variants therefore share the same filename.
