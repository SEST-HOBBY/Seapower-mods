# V-22 鱼鹰 / SV-22 2024 — 1.1.45

包含美方 MV-22B、日方 V-22B 和假想 SV-22 2024 反潜型，统一归类为“舰载倾转旋翼机”。2026-10-12，用户确认当前 SV-22 连续吊放可以运行。

## 安装与更新

1. 安装并启用 Anchor Chain（创意工坊 ID：3380210757）及其要求的加载器。
2. 将 `V-22` 文件夹放入 `Sea Power_Data/StreamingAssets/`，确保 `_info.ini` 位于模组根目录。
3. 启用鱼鹰。更新插件后完全退出并重新启动游戏，避免同时启用另一份鱼鹰安装包。

当前机构插件为 1.1.45，甲板插件为 1.1.36，针对本机 Sea Power 0.8.5 Build 261008。此次仅整理文件和说明，沿用已经运行的插件及资源。

## 机型与功能

| 机型 | 国别 / 情景可用年份 | 功能 |
| --- | --- | --- |
| MV-22B | 美国海军陆战队 / 2007 | 运输、搜救、手动悬停、航路终点自动悬停 |
| V-22B | 日本陆上自卫队 / 2020 | 同美方运输型；独立灰蓝涂装及日方标识 |
| SV-22 | 假想美方反潜型 / 2024 | 浮标搜索、鱼雷攻击、连续吊放声呐任务、手动悬停；载员容量 0 |

美方保留 VMM-263、VMM-162，日方保留第107、第108飞行队。SV-22 的 2024 年是游戏可用日期。战役启用机型年份限制时，需要满足对应年份。

运输型提供 Empty、Transport、Ferry 装载；默认、运输和救援配置载员 32 人，基础整备时间 20 分钟。“低速搜救”选择 10 节及 20 英尺目标高度，实际救援还需满足游戏高度、速度和剩余载员空间条件。“悬停”选择 0 节并保留高度指令。

运输型在玩家非循环航路的最后一点可自动减速、悬停并锁定位置：目标和实际高度不超过 5000 英尺时进入，超过 5500 英尺时退出；新航路、航向或速度指令退出自动控制。

采用独立 Mk 54 Mod 1、SSQ-53G 和 SSQ-62F 配置，使用原版视觉资源。库存放在机舱内的独立储架槽位；投放时只有选中的弹药移至后舱门释放点，随后沿用原生降落伞、入水和制导流程。

SV-22 保留手动“悬停”，普通航路不自动悬停，速度菜单无“低速搜救”，载员容量为 0。设备性能、质量预算、投放包线及资料来源见 [SV22_PROTOTYPE.txt](SV22_PROTOTYPE.txt)。未公开的现代性能为游戏估算。

## 连续吊放声呐

从 ALFS 传感器菜单创建“吊放声呐航路点”，可以依次放置多个任务点。执行当前吊放任务时，SV-22 接近目标、降至约 35 英尺并减速悬停；短舱竖直、实际姿态稳定并满足原生速度、水深和设备条件后，开腹舱门下放探头。部署时检查实际 20–45 英尺高度；海况会影响安全高度。

探头入水后开始监听。原生新任务默认监听 120 秒；沿用任务设定时间，0 表示持续监听直至取消。监听结束后收回缆线和探头、关闭舱门，再继续下一点。正常结束恢复任务前的速度和高度指令。

玩家实际修改速度或高度、删除任务或切换任务会取消专用控制并请求回收。正在着陆、受油、关机或失控时交还原生控制。内部速度和高度刷新可正常进行，不会被当作玩家取消。

独立系统为 `SV22_2024_ALFS`；探头、材料和缆线沿用原版 AQS-13 外观，数据采用独立现代系统估算。SV-22 使用专用机腹舱口、左右舱门和内部收纳盒。

## 飞行、受油与甲板

- 最高速度配置为 275 节；运输型总航程 2200 公里，SV-22 总航程 1850 公里。
- 三型支持手动悬停、短舱倾转、起落架、机翼和桨叶折叠、停机音效；舰艇需具备适用的 VTOL 起降及回收条件。
- 海上最低高度为 20 英尺加原生海况波浪间距。低速垂直控制上限为爬升 12、下降 6 米/秒，垂直加速度 3 米/秒²，临近目标减速；前飞低速俯仰最多 15°，零速悬停保持水平。这些控制值属于游戏估算。
- 三型高度响应参数为非战斗/战斗 500/500 英尺。正常非战斗巡航、实际和指令航速至少 130 节且向上高度差超过 5 米时，使用原生 30 秒速度换高度策略；保留动力和爬升率上限，实际航速可能随爬升下降。
- 支持原生软管锥套空中受油；加油、着陆、甲板和坠毁处理保留原生控制。模组提供搜索雷达、光电、雷达告警、防御干扰和数据共享。
