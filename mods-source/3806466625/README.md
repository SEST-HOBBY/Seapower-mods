# MV-22B 鱼鹰 — 1.1.18

用于 Sea Power 的无武装倾转旋翼运输机，包含美海军陆战队和日本陆上自卫队版本。

## 安装

1. 安装并启用 Anchor Chain（创意工坊 ID：3380210757）及其要求的加载器。
2. 将压缩包中的 `V-22` 文件夹放入 `Sea Power_Data/StreamingAssets/`。`_info.ini` 必须位于 `V-22` 根目录。
3. 在模组管理中启用鱼鹰，并完全重启游戏。更新时先移走旧版文件夹，避免与创意工坊版本重复加载。

## 版本与航空队

鱼鹰保留两种机型：美国海军陆战队 MV-22B 和日本陆上自卫队 V-22B。美方可选 VMM-263、VMM-162；日方可选输送航空队第107、第108飞行队。各机型的默认条目使用所属版本的配置，两版统一归入“舰载倾转旋翼运输机”。

## 日方版本

在单位选择中使用“V-22B 鱼鹰, 陆上自卫队”。独立机型 jgsdf_mv22b_osprey 使用实机 91707 的灰蓝色涂装、日之丸与“陸上自衛隊”标识；机身模型、飞行动画、运输方案和甲板流程与原版鱼鹰共用。日方实机属于**陆上自卫队**，曾在海上自卫队舰艇上起降。

## 使用

- 方案：空载、运输、转场。默认、运输与救援任务的载员容量为 32 人；转场使用内部燃油，不增加外挂油箱。
- 三种方案的基础整备时间均为 20 分钟，实际进度受游戏甲板计时模式影响。舰船有可达直升机起飞点时，鱼鹰从该点垂直起飞。
- 保留黄蜂回收路线兼容修正及少量甲板计时日志。1.1.16 移除两版鱼鹰的空排烟资源配置，避免首次异步出库请求空路径。用户已确认 1.1.16 修复后的出库恢复正常。更新至 1.1.17 后请完全重启游戏，复测新尺寸下的甲板贴合、折叠和升降机通过情况。
- 海平面最高速度配置为 275 节，约 509.3 公里／小时；巡航档速度较低。
- 最大总航程配置为 2200 公里。往返救援需预留起降、悬停和备用油量。
- 搜救：选择运输方案，接近目标后选择“搜救悬停”；使用“慢速接近”调整位置。
- 设备：搜索雷达、先进光电、宽频段雷达告警和防御干扰，支持数据共享。雷达搜索上限为 220 公里；光电参数参考已安装的 F/A-18F Block III 模组。实际探测距离受目标、天气和视距影响。
- 动画：短舱在回收航线继续随实际空速倾转；进入着陆及甲板流程后保持垂直。机翼整流罩的前下段固定在机身上，其余部分随翼收纳，转轴跟随机背倾角。甲板停机、旋翼停稳后停止循环发动机声音；再次起飞时，转运及展开期间保持发动机循环音静音，机翼和桨叶展开完成且旋翼开始转动后恢复。
- 外观模型、机组与空间锚点按游戏固定翼惯例放大 1.6 倍，飞行性能参数保持原值。
- 支持中文及英文，名称随游戏语言显示。

## 素材

外观模型与基础贴图来自用户提供的 Bell Boeing V-22 Osprey 素材包。飞行员和替代引擎音效使用 Sea Power 游戏资源。本模组的搜索及防御设备为游戏功能配置，不代表真实飞机的完整航电清单。
