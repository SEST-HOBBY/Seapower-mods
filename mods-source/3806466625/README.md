# MV-22B 鱼鹰 — 1.1.11

用于 Sea Power 的无武装倾转旋翼运输机。

## 安装

1. 安装并启用 Anchor Chain（创意工坊 ID：3380210757）及其要求的加载器。
2. 将压缩包中的 `V-22` 文件夹放入 `Sea Power_Data/StreamingAssets/`。`_info.ini` 必须位于 `V-22` 根目录。
3. 在模组管理中启用鱼鹰，并完全重启游戏。更新时先移走旧版文件夹，避免与创意工坊版本重复加载。

## 使用

- 方案：空载、运输、转场。默认、运输与救援任务的载员容量为 32 人；转场使用内部燃油，不增加外挂油箱。
- 海平面最高速度配置为 275 节，约 509.3 公里／小时；巡航档速度较低。
- 最大总航程配置为 2200 公里。往返救援需预留起降、悬停和备用油量。
- 搜救：选择运输方案，接近目标后选择“搜救悬停”；使用“慢速接近”调整位置。
- 设备：搜索雷达、先进光电、宽频段雷达告警和防御干扰，支持数据共享。雷达搜索上限为 220 公里；光电参数参考已安装的 F/A-18F Block III 模组。实际探测距离受目标、天气和视距影响。
- 动画：短舱在回收航线继续随实际空速倾转；进入着陆及甲板流程后保持垂直。机翼整流罩的前下段固定在机身上，其余部分随翼收纳，转轴跟随机背倾角。甲板停机、旋翼停稳后停止循环发动机声音。
- 外观模型、机组与空间锚点按游戏固定翼惯例放大 1.45 倍，飞行性能参数保持原值。
- 支持中文及英文，名称随游戏语言显示。

## 素材

外观模型与基础贴图来自用户提供的 Bell Boeing V-22 Osprey 素材包。飞行员和替代引擎音效使用 Sea Power 游戏资源。本模组的搜索及防御设备为游戏功能配置，不代表真实飞机的完整航电清单。
