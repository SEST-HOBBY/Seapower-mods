# MV-22B 鱼鹰 — 1.1.31 本地测试版

1.1.31 为两版鱼鹰接入游戏原生软管锥套空中受油；加油任务期间让原生控制器接管速度和位置，避免终点悬停覆盖加油指令。RCS 改为参考原版机型的数值 50。当前 0.8.5 程序集编译和静态检查通过；空中加油、加油后的悬停以及实际起降回收仍需完全重启后验证。

用于 Sea Power 的无武装倾转旋翼运输机，包含美海军陆战队和日本陆上自卫队版本。

## 安装

1. 安装并启用 Anchor Chain（创意工坊 ID：3380210757）及其要求的加载器。
2. 将压缩包中的 `V-22` 文件夹放入 `Sea Power_Data/StreamingAssets/`。`_info.ini` 必须位于 `V-22` 根目录。
3. 在模组管理中启用鱼鹰，并完全重启游戏。更新时先移走旧版文件夹，避免与创意工坊版本重复加载。

## 版本与航空队

鱼鹰保留两种机型：美国海军陆战队 MV-22B 和日本陆上自卫队 V-22B。美方可选 VMM-263、VMM-162；日方可选输送航空队第107、第108飞行队。各机型的默认条目使用所属版本的配置，两版统一归入“舰载倾转旋翼运输机”。

## 日方版本

在单位选择中使用“V-22B 鱼鹰, 陆上自卫队”。独立机型 jgsdf_mv22b_osprey 使用实机 91707 的灰蓝色涂装、日之丸与“陸上自衛隊”标识；机身模型、飞行动画、运输方案和甲板流程与原版鱼鹰共用。日方实机属于**陆上自卫队**，曾在海上自卫队舰艇上起降。

## 使用

- 方案：空载、运输、转场。默认、运输与救援任务的载员容量为 32 人；转场使用内部燃油，不增加外挂油箱。
- 三种方案的基础整备时间均为 20 分钟，实际进度受游戏甲板计时模式影响。舰船有可达直升机起飞点时，鱼鹰从该点垂直起飞。
- 保留黄蜂回收路线兼容修正及甲板计时日志。1.1.21 针对重复航母回收时已对准升降机却未停机的问题，在鱼鹰静止且等待折叠时补发游戏原生停机请求；企业号上连续三次降落均已完成入库。更新后需完全重启游戏。1.1.16 已移除导致首次出库异常的空排烟资源配置。
- 海平面最高速度配置为 275 节，约 509.3 公里／小时；巡航档速度较低。
- 最大总航程配置为 2200 公里。往返救援需预留起降、悬停和备用油量。
- 空中受油：空载、运输、转场方案均支持软管锥套（ProbeAndDrogue），可接受具备对应供油系统的加油机补给。通过游戏原生加油命令操作；低油量自动寻找兼容加油机沿用原生规则。等待、接触和离队期间暂停自定义低速及终点悬停控制，任务完成或取消后恢复其可用性。
- 雷达截面：RCS=50 为参照原版 S-3/A-6（50）及 CH-46/HH-3（30）设定的游戏估算值，不是实测鱼鹰 RCS；原来的 Large 对应原版 10000 的大型舰艇级别。
- 搜救：选择运输方案，接近目标后选择“低速搜救”（10 节，同时下达 20 英尺目标高度），到位后选择“悬停”（0 节，保持当前高度指令）。速度菜单最低两档仅保留这两个选项。海上实际高度仍受海浪间距影响；游戏救援要求实际离表面高度不超过 55 英尺、速度不超过 12 节且有剩余载员空间。更新后需完全重启游戏复测。
- 航路终点自动悬停：对玩家下达的非循环航路，只有目标高度与当前高度均不高于 5000 英尺时，才在最后一个航路点前逐步减速，抵达后切换至零速悬停，并在停稳处保持位置。高于门槛时保持游戏原有巡航命令；已开始减速后，目标或当前高度超过 5500 英尺才退出，以避免门槛附近反复切换。循环航路点不会触发；重新下达航路、速度或航向命令会退出自动控制。手动悬停选项不受此高度规则影响。1.1.26 的游戏日志已两次确认终点零速、位置锁定及新航路退出；1.1.27 清理了误导性的速度覆盖日志，并收紧交接期的退出判断。
- 设备：搜索雷达、先进光电、宽频段雷达告警和防御干扰，支持数据共享。雷达搜索上限为 220 公里；光电参数参考已安装的 F/A-18F Block III 模组。实际探测距离受目标、天气和视距影响。
- 动画：短舱在回收航线继续随实际空速倾转；进入着陆及甲板流程后保持垂直。机翼整流罩的前下段固定在机身上，其余部分随翼收纳，转轴跟随机背倾角。甲板停机、旋翼停稳后停止循环发动机声音；再次起飞时，转运及展开期间保持发动机循环音静音，机翼和桨叶展开完成且旋翼开始转动后恢复。
- 外观模型、机组与空间锚点按游戏固定翼惯例放大 1.6 倍，飞行性能参数保持原值。
- 支持中文及英文，名称随游戏语言显示。
