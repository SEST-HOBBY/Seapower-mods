中国无人机合集 / Chinese UAV Collection
发布日期：2026-11-09。

包含翼龙2、无侦7、无侦10、九天、WJ-25 CCA，共5架飞机、34种可选挂载。
Includes YL-2, WZ-7, WZ-10, Jiutian and WJ-25 CCA: five aircraft and 34 selectable loadouts.

先按 Anchor Chain 官方说明安装预加载器，再订阅 Anchor Chain。仅订阅工坊条目不会安装预加载器。
Install the Anchor Chain preloader first, then subscribe to Anchor Chain.
https://seapower-modders.github.io/AnchorChain/install-anchor-chain.html

本地分享包安装 / Local shared ZIP
退出游戏，把 ZIP 中的 PLAN UAV COLLECTION 文件夹放到 Sea Power_Data/StreamingAssets 下。
五个 DLL 保留在模组根目录，由 Anchor Chain 加载，不要再手动复制到 BepInEx/plugins。
关闭旧的独立五机包及旧整合包，避免同名单位覆盖。启用本包与前置后重新启动游戏。
With the game closed, extract PLAN UAV COLLECTION into Sea Power_Data/StreamingAssets.
Keep the five DLLs in the mod folder. Anchor Chain loads them there; do not install additional copies in BepInEx/plugins.
Remove old standalone/collection installations before enabling this package, then restart the game.

旧版使用者：本包的加载入口会识别已运行的旧路径插件，避免重复启动，但旧 DLL 不会随工坊自动更新。
使用过旧本地版时，应移除旧版 CCA53536.Runtime.dll、JiutianReferenceUnits.dll、WZ7GearRuntime.dll。
SPX.PLANMissileMissionControl.dll 可能同时服务其他模组；如已有安装，保留且确认版本一致，不要随意删除其他模组的插件。
Legacy local plugins can prevent Workshop updates from taking effect. The loader avoids double startup; keep any shared SPX plugin in sync.
