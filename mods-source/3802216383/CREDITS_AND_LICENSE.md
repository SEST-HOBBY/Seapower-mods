# Credits, Source, and Release Conditions

## Purchased ship source

This private transition build was generated from the user-supplied purchased
files `hyuga1.1.blend`, `hyuga1.1.fbx`, and `textures.rar`. The archive contains
only the converted in-game mesh and optimized runtime textures; it does not
contain the original editable source files.

The seller/creator name, storefront listing, and licence text were not embedded
in the supplied files. Keep the purchase receipt and licence with the project.
Before any public or Workshop release, confirm that the licence permits
distribution of the converted model and textures as part of a game mod, and add
the creator's requested credit wording here. Purchase alone does not necessarily
grant redistribution rights.

## Other assets

The articulated CIWS assemblies and configured game systems are loaded from the
listed Euromod/Sea Power dependencies and are not copied into this archive. The
source FBX's baked CIWS meshes were intentionally excluded.
