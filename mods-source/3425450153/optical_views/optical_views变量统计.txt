============================================================
  望远镜 / 观瞄系统「可使用变量」完整统计
============================================================

一、基础标识变量（必选）
------------------------------------------------------------
变量名           类型      说明
------------------------------------------------------------
DisplayName      string    显示名称
OverlayTexture   path      HUD 叠加纹理路径
Labels           string    倍率/模式标签
------------------------------------------------------------
✅ 所有文件均包含


二、光学参数变量（核心）
------------------------------------------------------------
变量名             类型          说明
------------------------------------------------------------
FOVs              float/list    视场角（度），多值=多档变焦
RotationDamping   float/list    转动平滑阻尼
------------------------------------------------------------
📌 FOV 越小 → 放大倍率越高
📌 多值示例：5.0,2.8 = 8× / 16× 两档
📌 RotationDamping 双值常为 [水平, 垂直]


三、后处理滤镜变量
------------------------------------------------------------
变量名             类型      说明
------------------------------------------------------------
PostProcessFilters list     可用的后处理滤镜集合
DefaultFilter      string   默认启用的滤镜
AllowFilterCycle   bool     是否允许循环切换滤镜


四、已出现的滤镜种类全集（共 9 种）
------------------------------------------------------------
滤镜 ID                 含义
------------------------------------------------------------
None                    无滤镜（裸眼）
[ - - ]                    占位/普通模式
LLLTV_5_step,LLLTV_5_step_temporal_ghosting      垃圾夜视
Night_Vision_LLLTV         红光低能见度夜视
LLLTV-BW                黑白低能见度夜视
LLLTV                   绿光低能见度夜视
TBHO                    增强绿光夜视
TBHO-CB                 增强黑白夜视
KHB                     热融合
FLIR                    红外
ROS - TV                黑白电视
ROS - WHOT          增强白热
ROS - BHOT           增强黑热


------------------------------------------------------------


五、按设备类型的变量模板
============================================================

【1】普通舰用双筒镜（8×50 / 7×50）
------------------------------------------------------------
DisplayName=
OverlayTexture=
FOVs=
Labels=
RotationDamping=
PostProcessFilters=None
DefaultFilter=None
AllowFilterCycle=False
------------------------------------------------------------

【2】高级舰桥稳像镜（20×120 STAB）
------------------------------------------------------------
DisplayName=
OverlayTexture=
FOVs=
Labels=
RotationDamping=
PostProcessFilters=[ - - ],LLLTV-BW,KHB,TBHO
DefaultFilter=LLLTV-BW
AllowFilterCycle=True
------------------------------------------------------------

【3】潜望镜（Periscope）
------------------------------------------------------------
FOVs=5.0,2.8
Labels=PERISCOPE 8x,PERISCOPE 16x
PostProcessFilters=[ - - ],LLLTV-BW / TBHO
DefaultFilter=[ - - ]
AllowFilterCycle=True
------------------------------------------------------------

【4】航空光电吊舱（EO Station）
------------------------------------------------------------
FOVs=6.0,2.0
Labels=EO WIDE,EO NARROW
RotationDamping=0.35,0.15
PostProcessFilters=FLIR,[ - - ]
DefaultFilter=FLIR
AllowFilterCycle=True
------------------------------------------------------------

总结：共 7 个可用变量 + 9 种滤镜模式
      支持多档变焦、稳像阻尼、夜视/热成像自由切换
