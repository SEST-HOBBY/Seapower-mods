SEST INTEGRATION PACK - GAME BUILDS AND BUNDLED FEATURES

SEST's code is matched, file by file, to particular game builds: SETUP
identifies them by SHA-256 of Sea Power_Data\Managed\Seapower-Scripts.dll.
The pack's campaigns and data files do not depend on that file; they are
built for the game version the pack's _info.ini declares. The build report
in step 1 changes nothing; the bundled feature installation runs at the end
of SETUP.

CURRENT RELEASE: SEA POWER 0.9.0 Build 261111 (11 November 2026)
- The pack's data is built for 0.9.0. SEST's code is not matched to it yet:
  Runtime Fixes, UI Follow-up and the bundled beta features stay off under
  their own checks, and SETUP makes no code changes. If SEST's beta files
  are installed from an earlier build, SETUP puts the normal plugins back.
- What is off without SEST's code: F11 World Operations and its awards, the
  F11 cost totals and campaign costs panel, the Red Line runtime ribbons and
  the runtime corrections. The campaigns, units and data load without them.
- SETUP's step 1 reports this file as one no SEST plugin is matched to and
  gives the version the game's own changelog names.

REVIEWED BUILD: 0.8.7 Build 261107, the public beta before 0.9.0
(Seapower-Scripts.dll 499675cd...)
- R13 includes F11 World Operations, world service progress, campaign costs,
  Coordinated Strike styling/cost summaries, the debrief mission ribbons and
  reviewed beta compatibility.
- Existing enabled SEST beta installation: close the game and run SETUP once.
- First installation: run SETUP, launch to the main menu, wait about ten
  seconds, quit, then run SETUP again. A successful menu probe is required.
- After Steam updates the Workshop item, close the game and rerun SETUP.
- The feature archive ships inside this Workshop item. It extracts to an
  external user cache; the installer backs up code before replacing it.
- Original native game and author DLLs, campaign saves and original restore
  backups are retained. Unknown installed code or author references stop
  feature installation. Keep the error and diagnostic report for review.
- Managed/fixture checks passed; native gameplay acceptance is still required.

OLDER BETAS AND ANY OTHER BUILD
