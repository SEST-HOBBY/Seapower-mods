SEST INTEGRATION PACK - GAME BUILDS AND BUNDLED FEATURES

SEST's code is matched, file by file, to particular game builds: SETUP
identifies them by SHA-256 of Sea Power_Data\Managed\Seapower-Scripts.dll.
The pack's campaigns and data files do not depend on that file; they are
built for the game version the pack's _info.ini declares. The build report
in step 1 changes nothing; the bundled feature installation runs at the end
of SETUP.

CURRENT RELEASE: SEA POWER 0.9.2 Build 261113 (13 November 2026)
(Seapower-Scripts.dll 3f56861f...)
- The pack's data is built for 0.9.2, and the bundled features are R14
  (SEST Runtime 1.7.0, UI 1.5.0), reviewed for this build: F11 World
  Operations, world service progress, campaign costs, Coordinated Strike
  styling/cost summaries and the debrief mission ribbons.
- First installation: run SETUP, launch to the main menu, wait about ten
  seconds, quit, then run SETUP again. A successful menu probe is required.
- Existing enabled SEST feature installation: close the game and run SETUP
  once. After Steam updates the Workshop item, close the game and rerun
  SETUP.
- Anchor Chain's own preloader logs "Could not find AnchorChain chainloader"
  on this build: it looks before the Workshop folders are registered.
  SEST's bundled loader waits for them and starts Anchor Chain itself, and
  SETUP's step 1 reports a last launch in which it ran to the end as [ok].
- Runtime Fixes 1.5.0 and UI Follow-up, matched to Build 261021, stay off on
  this build under their own checks; the bundled features replace them.
- The feature archive ships inside this Workshop item. It extracts to an
  external user cache; the installer backs up code before replacing it.
- Original native game and author DLLs, campaign saves and original restore
  backups are retained. Unknown installed code or author references stop
  feature installation. Keep the error and diagnostic report for review.
- Managed/fixture checks passed; native gameplay acceptance is still required.
